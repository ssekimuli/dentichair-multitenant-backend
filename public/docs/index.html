Introduction

Base URL: http://localhost

Chart Management System API Documentation

This API provides endpoints for managing dental clinic operations including patients, appointments, invoices, and dental records.

Authenticating requests

This API is not authenticated.

Appointments

Endpoints for managing patient appointments, scheduling, and appointment status. Includes queue management and appointment tracking features.

Get All Appointments

requires authentication

Retrieve a list of appointments with optional filtering by branch, date, or status. Returns complete appointment details including patient, doctor, and branch information.

Example request:
curl --request GET \
    --get "http://localhost/api/appointments?branch_id=b1&date=2024-07-20&status=Scheduled" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost/api/appointments"
);

const params = {
    "branch_id": "b1",
    "date": "2024-07-20",
    "status": "Scheduled",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());
